# 微信视频号一键发布（独立发布包）

本文件夹可**整体复制到任意一台 Windows 电脑**，安装依赖后即可运行，无需依赖主项目其他目录。

## 环境要求

- **系统**：Windows 10/11
- **已安装并登录**：PC 版微信（桌面版微信需已打开）
- **视频文件**：桌面需有 `aaa.mp4`（或修改脚本中的路径）

## 安装与运行

1. **复制整个 `publish` 文件夹**到目标电脑（必须包含 `pyweixin-main` 子文件夹、`run.py`、`requirements.txt`）。

2. **安装 Python 依赖**（建议使用虚拟环境）：
   ```bash
   cd publish
   pip install -r requirements.txt
   ```

3. **运行脚本**：
   ```bash
   python run.py
   ```

4. **前置条件**：
   - 微信已打开并登录
   - 桌面有 `aaa.mp4`（或已在脚本中改为你的视频路径）

## 脚本流程简述

1. 激活微信主窗口  
2. 点击左侧视频号 logo，进入视频号主界面  
3. 点击右上角头像，进入“点赞和收藏”  
4. 点击左侧“我的视频号”  
5. 点击“发表视频”  
6. 点击“+ 上传 8 小时以内视频”  
7. 在文件对话框中自动输入桌面 `aaa.mp4` 路径并回车  
8. 最大化窗口 → 滚动到短标题输入框 → 填写 6 字短标题（默认“自动化测试标题”）→ 点击“发表” → 等待 10 秒 → 关闭视频号窗口  

步骤间有 3–6 秒随机延迟，每步超时约 15 秒（第 8 步约 25 秒）。

## 修改视频路径

在 `run.py` 中搜索 `Desktop`, `aaa.mp4`，将：

```python
path_to_type = os.path.join(os.path.expanduser("~"), "Desktop", "aaa.mp4")
```

改为你的视频绝对路径即可。

## 依赖说明

- **pywinauto**：操作微信窗口（UIA）
- **pywin32**：剪贴板等（pyweixin 内部可能用到）

`pyweixin-main` 为项目内嵌库，已随本文件夹一起复制，无需单独安装。
