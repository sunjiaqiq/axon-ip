## 🚀 使用方法

### 方法1：直接使用测试脚本
```bash
cd douyin-mcp-server-main
py -3 test_extract_with_mcp.py
```

### 方法2：使用命令行工具
```bash
cd douyin-mcp-server-main
set API_KEY=${SILICONFLOW_API_KEY}
py -3 douyin-video/scripts/douyin_downloader.py -l "抖音分享链接" -a extract -o ./output
```

### 方法3：通过 FastAPI 接口（已集成）
```bash
# 启动服务
uvicorn pixelle_wrapper.main:app --port 38810 --reload

# 调用接口
POST http://localhost:38810/api/copywriting/parse_link
{
  "link": "抖音分享链接"
}
```
