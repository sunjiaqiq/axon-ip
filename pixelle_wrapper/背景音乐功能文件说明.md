## 📋 核心函数说明

### `add_background_music` 函数

**位置**：`pixelle_wrapper/ai_pipeline/video_editor.py` (第 371-507 行)

**函数签名**：
```python
def add_background_music(
    video_path: str,                    # 视频文件路径
    music_path: str,                    # 背景音乐文件路径
    output_path: Optional[str] = None, # 输出路径（可选）
    music_volume: float = 0.3,         # 背景音乐音量（0.0-1.0）
    original_volume: float = 1.0,       # 原音频音量（0.0-1.0）
    fade_in: float = 0.0,              # 淡入时长（秒）
    fade_out: float = 0.0,             # 淡出时长（秒）
    loop: bool = True                  # 是否循环播放
) -> Optional[Path]:
```

**功能流程**：
1. ✅ 验证文件存在
2. ✅ 加载视频和音频
3. ✅ 处理时长（循环/裁剪）
4. ✅ 调整音量
5. ✅ 应用淡入淡出
6. ✅ 混合音频
7. ✅ 合成视频
8. ✅ 输出文件
9. ✅ 清理资源
