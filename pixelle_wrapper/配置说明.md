# Pixelle-Video Wrapper 配置说明

## 问题：无法找到 Pixelle-Video 项目

如果看到以下错误：
```
[警告] 无法导入 Pixelle-Video: No module named 'pixelle_video'
[警告] 未检测到 Pixelle-Video 路径
```

## 解决方案

### 方法1：使用配置文件（推荐）

1. **复制配置文件模板**
   ```bash
   cd pixelle_wrapper
   copy config.json.example config.json
   ```

2. **编辑 config.json**
   打开 `pixelle_wrapper/config.json`，修改路径：
   ```json
   {
     "pixelle_video_path": "Y:/Video-main"
   }
   ```
   将 `Y:/Video-main` 替换为你的实际 Pixelle-Video 项目路径。

3. **重启服务**
   重启 `pixelle_wrapper` 服务，路径会自动加载。

### 方法2：使用环境变量

**Windows (CMD):**
```cmd
set PIXELLE_VIDEO_ROOT=Y:\Video-main
```

**Windows (PowerShell):**
```powershell
$env:PIXELLE_VIDEO_ROOT = "Y:\Video-main"
```

**Linux/Mac:**
```bash
export PIXELLE_VIDEO_ROOT=/path/to/Video-main
```

### 方法3：检查常见路径

系统会自动检查以下常见路径：
- `Y:/Video-main`
- `D:/Video-main`
- `C:/Video-main`
- `E:/Video-main`

如果你的路径在这些位置，系统应该能自动检测到。

## 验证配置

启动服务后，查看日志，应该看到：
```
[Wrapper] 从配置文件检测到 Pixelle-Video 路径: Y:\Video-main
[Wrapper] [OK] Pixelle-Video 导入成功
```

如果看到：
```
[Wrapper] 警告: 未检测到 Pixelle-Video 路径
```

说明配置未生效，请检查：
1. 配置文件路径是否正确
2. 环境变量是否设置
3. Pixelle-Video 项目路径是否存在
4. 路径中是否包含 `pixelle_video` 模块目录

## 常见问题

### Q: 路径存在但无法导入模块？

A: 确保路径中包含 `pixelle_video` 目录，例如：
```
Y:/Video-main/
  ├── pixelle_video/    ← 这个目录必须存在
  ├── workflows/
  └── config.yaml
```

### Q: 配置文件不生效？

A: 
1. 确保文件名为 `config.json`（不是 `config.json.example`）
2. 确保文件在 `pixelle_wrapper` 目录下
3. 确保 JSON 格式正确（使用双引号）
4. 重启服务

### Q: 环境变量不生效？

A:
1. 确保在启动服务**之前**设置环境变量
2. 如果使用 CMD，确保在同一个会话中启动服务
3. 如果使用 PowerShell，确保使用 `$env:` 语法

## 推荐配置方式

**开发环境：** 使用配置文件 `config.json`（便于版本控制）

**打包环境：** 使用环境变量或安装时自动检测
