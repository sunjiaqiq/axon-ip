# 抖音发布元素定位信息

## 1. "完成"按钮（封面选择后的完成按钮）

### 方式1: tooltip-container选择器
```xpath
//*[@id='tooltip-container']/button[1]
```

### 方式2: 文本匹配（备用方案）
```xpath
//span[@class='semi-button-content' and contains(text(), '完成')]
//span[contains(@class, 'semi-button-content') and contains(text(), '完成')]
//span[contains(text(), '完成')]
//button[contains(text(), '完成')]
```

### CSS选择器
```css
span.semi-button-content
```

### 点击方式
1. 普通点击: `button.click()`
2. JavaScript点击: `driver.execute_script("arguments[0].click();", button)`
3. 滚动到可见: `driver.execute_script("arguments[0].scrollIntoView({block: 'center'});", button)`

## 5. "确定"按钮（封面选择对话框）

### XPath选择器
```xpath
//*[@id='dialog-0']/div/div/div/div[4]/button[2]
//*[@id='dialog-0']//button[contains(text(), '确定')]
//*[@id='dialog-0']//button[contains(@class, 'primary') and contains(text(), '确定')]
//button[contains(@class, 'button-dhIUZE') and contains(@class, 'primary') and contains(text(), '确定')]
//button[contains(text(), '确定')]
```

### CSS选择器
```css
#dialog-0 > div > div > div > div:nth-child(4) > button:nth-child(2)
#dialog-0 button.primary
button.button-dhIUZE.primary
```

### 颜色识别（备用）
- 背景色: `rgb(254, 44, 85)` 或包含 `254` 或 `255`

## 调试建议

### 1. 检查元素是否存在
```python
# 在浏览器控制台执行
document.querySelector("//*[@id='tooltip-container']/button[1]")
document.querySelector("//button[contains(text(), '发布')]")
```

### 2. 检查元素是否可见
```python
element = driver.find_element(By.XPATH, "//button[contains(text(), '发布')]")
print("是否可见:", element.is_displayed())
print("是否可点击:", element.is_enabled())
print("元素位置:", element.location)
print("元素大小:", element.size)
```

### 3. 检查元素文本
```python
element = driver.find_element(By.XPATH, "//button[contains(text(), '发布')]")
print("按钮文本:", element.text)
print("按钮HTML:", element.get_attribute('outerHTML'))
```

### 4. 检查页面状态
```python
print("当前URL:", driver.current_url)
print("页面标题:", driver.title)
```

## 常见问题

1. **"完成"按钮找不到**
   - 检查 `tooltip-container` 是否存在
   - 检查按钮是否在iframe中
   - 检查是否需要等待页面加载

2. **"发布"按钮点击无效**
   - 检查按钮是否被遮挡
   - 检查按钮是否禁用（disabled）
   - 尝试使用JavaScript点击
   - 检查是否有验证码或弹窗

3. **标题/描述输入失败**
   - 检查输入框是否可编辑
   - 检查是否需要先点击输入框
   - 对于contenteditable的div，使用JavaScript设置
