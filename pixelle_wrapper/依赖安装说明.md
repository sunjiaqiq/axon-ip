# Pixelle-Video 依赖安装说明

## 问题

如果看到以下错误：
- `No module named 'comfykit'`
- `Pixelle-Video 未初始化`
- `500 Server Error` 在调用 `/api/generate` 时

说明缺少 Pixelle-Video 的依赖。

## 解决方案

### 方法 1：在 Pixelle-Video 项目目录安装依赖

```bash
cd Y:\Video-main
pip install -r requirements.txt
```

### 方法 2：单独安装缺失的模块

```bash
pip install comfykit
```

### 方法 3：检查 Pixelle-Video 环境

确保你在正确的 Python 环境中：

```bash
# 检查当前 Python 环境
python --version
where python

# 如果 Pixelle-Video 使用 conda 环境
conda activate pixelle_env
pip install -r requirements.txt
```

## 验证安装

安装完成后，重启 Wrapper 服务，应该看到：

```
[Wrapper] ✅ Pixelle-Video 导入成功
[Wrapper] 正在初始化 Pixelle-Video...
[Wrapper] ✅ Pixelle-Video 初始化完成
```

## 常见依赖

Pixelle-Video 通常需要以下依赖：
- `comfykit` - ComfyUI 工具包
- `torch` - PyTorch
- `transformers` - Hugging Face Transformers
- 其他 AI 相关库

请参考 `Y:\Video-main\requirements.txt` 获取完整列表。
