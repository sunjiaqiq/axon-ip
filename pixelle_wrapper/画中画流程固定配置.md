# 画中画功能 - 固定流程配置

## 📋 固定配置参数

### 默认参数设置

```python
add_picture_in_picture(
    host_video: str,                    # 主视频路径（口播视频）
    showcase_videos: List[str],         # 展示视频列表
    output_path: Optional[str] = None,  # 输出路径
    start_time: float = 3.0,            # 画中画开始时间（秒）
    end_before: float = 5.0,            # 结束前多少秒停止画中画
    position: str = 'center',           # 位置：中间
    size_ratio: float = 2/3,            # 大小：三分之二（66.7%）
    loop: bool = True,                  # 循环播放
    effect: str = 'zoom'               # 特效：缩放进入（固定）
)
```

---

## ✅ 固定配置说明

### 1. **位置（Position）**
- **固定值**: `'center'`（中间）
- **说明**: 画中画视频显示在屏幕正中央

### 2. **大小（Size Ratio）**
- **固定值**: `2/3`（约 0.667，即 66.7%）
- **说明**: 画中画占据屏幕的三分之二大小

### 3. **特效（Effect）**
- **固定值**: `'zoom'`（缩放进入）
- **说明**: 画中画从小（30%）逐渐放大到正常大小（100%）
- **动画时长**: 前0.5秒完成缩放动画

### 4. **时间控制**
- **开始时间**: `3.0` 秒后开始显示画中画
- **结束时间**: 视频结束前 `5.0` 秒停止画中画
- **说明**: 前3秒和后5秒是纯口播，中间部分显示画中画

### 5. **音频控制**
- **画中画音频**: 完全静音（`without_audio()`）
- **主视频音频**: 保留原音频

### 6. **循环播放**
- **固定值**: `True`
- **说明**: 如果展示视频时长不足，会自动循环播放

---

## 🎬 特效详情

### Zoom（缩放进入）特效

**效果描述**:
- 画中画从屏幕外或小尺寸（30%）开始
- 在0.5秒内逐渐放大到正常大小（100%）
- 之后保持正常大小直到结束

**实现代码**:
```python
def zoom_func(t):
    if t < 0.5:  # 前0.5秒从小变大
        scale = 0.3 + (t / 0.5) * 0.7  # 从30%到100%
    else:
        scale = 1.0
    return (int(original_w * scale), int(original_h * scale))

pip_clip = pip_clip.resize(zoom_func)
```

## 📊 流程总结

### 完整流程

1. **输入准备**
   - 口播视频（主视频）
   - 展示视频（画中画视频，可多个）

2. **参数设置**（已固定）
   - 位置：中间
   - 大小：三分之二
   - 特效：缩放进入
   - 时间：3秒后开始，结束前5秒停止
   - 音频：画中画静音

3. **处理过程**
   - 加载主视频和展示视频
   - 调整展示视频大小（66.7%）
   - 应用缩放进入特效
   - 设置位置和时间段
   - 合成最终视频

4. **输出结果**
   - 生成带画中画的视频文件
   - 保持主视频音频
   - 画中画静音
