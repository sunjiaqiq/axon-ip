- 直接双击 `PixelleWrapper.exe`
- 会显示控制台窗口，显示服务启动信息


### 2. 检查服务状态

服务启动后，应该看到：
```
Starting server at http://127.0.0.1:38887
API Docs: http://127.0.0.1:38887/docs
```

### 3. 测试 API 接口

#### 方式1：浏览器测试
打开浏览器访问：
- 健康检查：http://127.0.0.1:38887/health
- API 文档：http://127.0.0.1:38887/docs

#### 方式2：使用 PyQt UI 测试
1. 启动主 UI 程序
2. 点击右上角 🎬 按钮
3. 测试完整流程：
   - 上传人物照片
   - 输入文案
   - 点击生成
   - 查看进度
   - 下载视频

### 4. 测试完整流程

#### 步骤1：设置 API Key
```bash
curl -X POST http://127.0.0.1:38887/api/set_key \
  -H "Content-Type: application/json" \
  -d "{\"api_key\": \"your-api-key\"}"
```

#### 步骤2：上传人物照片
```bash
curl -X POST http://127.0.0.1:38887/api/avatar \
  -F "file=@path/to/avatar.jpg"
```

#### 步骤3：设置文案
```bash
curl -X POST http://127.0.0.1:38887/api/text \
  -H "Content-Type: application/json" \
  -d "{\"text\": \"这是测试文案\"}"
```

#### 步骤4：生成视频
```bash
curl -X POST http://127.0.0.1:38887/api/generate
```

返回：
```json
{
  "success": true,
  "task_id": "uuid-string",
  "message": "任务已创建"
}
```

#### 步骤5：查询进度
```bash
curl http://127.0.0.1:38887/api/task/{task_id}
```

#### 步骤6：下载视频
```bash
curl http://127.0.0.1:38887/api/download/{task_id} -o video.mp4
```

## 注意事项

### 1. Pixelle-Video 路径
EXE 运行时需要访问 `Y:/Video-main` 路径。

如果路径不同，需要：
- 修改 `main.py` 中的 `PIXELLE_VIDEO_PATH`
- 重新打包

### 2. 端口占用
如果端口 38887 被占用，EXE 会报错。

解决方法：
- 关闭占用端口的程序
- 或修改 `main.py` 中的端口号，重新打包

### 3. 首次运行
EXE 首次运行可能需要几秒钟解压，请耐心等待。

### 4. 控制台窗口
EXE 会显示控制台窗口，可以看到：
- 服务启动信息
- API 请求日志
- 错误信息
- 任务进度信息

## 常见问题

### Q: EXE 无法启动
A: 检查：
1. 是否有杀毒软件拦截
2. 查看控制台错误信息
3. 确认 Pixelle-Video 路径是否正确

### Q: 服务启动失败
A: 检查：
1. 端口 38887 是否被占用
2. Pixelle-Video 路径是否存在
3. 查看控制台错误信息

### Q: 生成视频失败
A: 检查：
1. API Key 是否已设置
2. 文案是否已设置
3. Pixelle-Video 服务是否正常
4. 查看控制台错误信息

### Q: 进度不更新
A: 检查：
1. 任务状态是否为 "running"
2. 查看控制台是否有进度日志
3. 确认 Pixelle-Video 是否正常生成
