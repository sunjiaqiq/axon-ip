# 浏览器自动化技术说明

## 使用的技术：Playwright

我们系统使用的是 **Playwright** 来进行浏览器自动化操作。

### Playwright 是什么？

Playwright 是由 Microsoft 开发的现代化浏览器自动化框架，支持：
- Chrome/Chromium
- Firefox
- Safari/WebKit

### 我们如何使用 Playwright？

1. **启动浏览器**
   ```python
   from playwright.async_api import async_playwright
   
   playwright = await async_playwright().start()
   browser = await playwright.chromium.launch_persistent_context(
       user_data_dir="browser_data",
       channel="chrome"  # 使用系统安装的Chrome
   )
   ```

2. **持久化浏览器上下文**
   - 使用 `launch_persistent_context` 创建持久化浏览器
   - 登录信息保存在 `browser_data/` 目录
   - 浏览器关闭后，登录状态仍然保留

3. **操作浏览器**
   - 打开页面：`page.goto(url)`
   - 搜索元素：`page.query_selector()`
   - 提取内容：`page.content()`
   - 下载文件：通过 `page.evaluate()` 执行 JavaScript

### 为什么选择 Playwright？

1. **现代化**：比 Selenium 更现代，API 更简洁
2. **性能好**：直接通过 CDP (Chrome DevTools Protocol) 通信
3. **功能强**：支持多浏览器、网络拦截、文件下载等
4. **稳定性**：自动等待元素加载，减少时序问题

### 与 Selenium 的区别

- **Selenium**：通过 WebDriver 协议，需要单独的驱动
- **Playwright**：直接通过浏览器协议（CDP），更高效

### 当前配置

- **浏览器**：Chrome（系统安装的版本）
- **模式**：持久化上下文（保持登录状态）
- **反检测**：已配置隐藏自动化标识的参数和脚本

### 技术栈总结

```
Python
  └── Playwright (浏览器自动化)
      └── Chrome/Chromium (实际浏览器)
          └── CDP (Chrome DevTools Protocol) - 底层通信协议
```
