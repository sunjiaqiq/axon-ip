## 🎬 MoviePy 支持的特效类型

### 1. 转场特效（Transition Effects）

#### 淡入淡出（Fade）
```python
# 淡入效果（从透明到不透明）
pip_clip = pip_clip.fadein(1.0)  # 1秒淡入

# 淡出效果（从不透明到透明）
pip_clip = pip_clip.fadeout(1.0)  # 1秒淡出

# 淡入淡出组合
pip_clip = pip_clip.fadein(0.5).fadeout(0.5)
```

#### 交叉淡入淡出（Crossfade）
```python
# 两个视频之间的交叉淡入淡出
from moviepy.editor import crossfadein, crossfadeout
```

---

### 2. 动画特效（Animation Effects）

#### 缩放动画（Zoom）
```python
# 从小到大的缩放动画
pip_clip = pip_clip.resize(lambda t: 1 + 0.1*t)  # 随时间放大

# 从大到小的缩放动画
pip_clip = pip_clip.resize(lambda t: 1.5 - 0.1*t)  # 随时间缩小
```

#### 移动动画（Move）
```python
# 从右侧滑入
pip_clip = pip_clip.set_position(lambda t: ('right', 'center'))

# 从下方滑入
pip_clip = pip_clip.set_position(lambda t: ('center', lambda t: h if t<0.5 else h-100))
```

#### 旋转动画（Rotate）
```python
# 旋转效果
pip_clip = pip_clip.rotate(lambda t: 360*t)  # 旋转360度
```

---

### 3. 视频滤镜（Video Filters）

#### 模糊效果（Blur）
```python
from moviepy.video.fx import blur
pip_clip = pip_clip.fx(blur, 5)  # 模糊半径5
```

#### 亮度调整（Brightness）
```python
pip_clip = pip_clip.fx(lambda c: c.fl_image(lambda f: f*1.2))  # 增加20%亮度
```

#### 对比度调整（Contrast）
```python
pip_clip = pip_clip.fx(lambda c: c.fl_image(lambda f: np.clip((f-128)*1.5+128, 0, 255)))
```

#### 色彩调整（Color）
```python
# 黑白效果
pip_clip = pip_clip.fx(lambda c: c.fl_image(lambda f: np.dot(f[...,:3], [0.299, 0.587, 0.114])))
```

---

### 4. 边框和阴影（Border & Shadow）

#### 添加边框
```python
# 使用 CompositeVideoClip 添加边框层
border_clip = ImageClip(...).set_duration(...)
```

#### 添加阴影
```python
# 创建阴影层
shadow_clip = pip_clip.fx(lambda c: c.fl_image(lambda f: f*0.3))  # 半透明阴影
shadow_clip = shadow_clip.set_position((pip_x+5, pip_y+5))  # 偏移位置
```

---

### 5. 特殊效果（Special Effects）

#### 马赛克（Mosaic）
```python
pip_clip = pip_clip.resize(0.1).resize(10)  # 先缩小再放大，形成马赛克
```

#### 镜像效果（Mirror）
```python
pip_clip = pip_clip.fx(lambda c: c.fl_image(lambda f: np.fliplr(f)))
```

#### 倒影效果（Reflection）
```python
# 创建倒影
reflection = pip_clip.fx(lambda c: c.fl_image(lambda f: np.flipud(f)))
```

## 🎯 可以实现的画中画特效

### 特效1: 淡入淡出
**效果**: 画中画从透明逐渐显示，结束时逐渐消失
```python
pip_clip = pip_clip.fadein(0.5).fadeout(0.5)
```

### 特效2: 缩放进入
**效果**: 画中画从小变大进入画面
```python
pip_clip = pip_clip.resize(lambda t: min(1.0, 0.5 + t*2) if t < 0.5 else 1.0)
```

### 特效3: 滑入动画
**效果**: 画中画从右侧滑入
```python
pip_clip = pip_clip.set_position(lambda t: (w if t<0.3 else pip_x, pip_y))
```

### 特效4: 旋转进入
**效果**: 画中画旋转进入
```python
pip_clip = pip_clip.rotate(lambda t: 360*(1-t) if t<0.5 else 0)
```

### 特效5: 模糊到清晰
**效果**: 画中画从模糊逐渐变清晰
```python
pip_clip = pip_clip.fx(blur, lambda t: max(0, 10-20*t))
```

### 特效6: 边框高亮
**效果**: 画中画周围有发光边框
```python
# 需要添加边框层
```

### 特效7: 弹跳效果
**效果**: 画中画弹跳进入
```python
pip_clip = pip_clip.set_position(lambda t: (pip_x, pip_y - 50*abs(np.sin(t*5))))
```

### 特效8: 闪烁出现
**效果**: 画中画闪烁几次后稳定显示
```python
pip_clip = pip_clip.fx(lambda c: c.set_opacity(lambda t: 1.0 if int(t*5)%2==0 else 0.5))
```
