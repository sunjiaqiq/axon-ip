# 画中画功能说明

## 📋 功能需求

### 场景描述
- **主视频**: 口播视频（老板介绍店铺服务）
- **叠加视频**: 店铺环境、工作流程、产品展示等视频
- **效果**: 画中画（Picture-in-Picture, PiP）

### 时间轴设计
```
时间轴示例（假设口播视频30秒）:
┌─────────────────────────────────────────────────┐
│ 0-3秒:  纯口播（无画中画）                      │
├─────────────────────────────────────────────────┤
│ 3-25秒: 口播 + 画中画（循环播放展示视频）        │
│         ┌─────────────┐                        │
│         │  口播视频    │                        │
│         │             │                        │
│         │    ┌────┐   │  ← 画中画（店铺环境）  │
│         │    │展示│   │                        │
│         │    └────┘   │                        │
│         └─────────────┘                        │
├─────────────────────────────────────────────────┤
│ 25-30秒: 纯口播（无画中画，最后5秒）            │
└─────────────────────────────────────────────────┘
```

---

## 🎯 功能特性

### ✅ 已实现的功能
1. **时间控制**
   - 前3秒：纯口播
   - 3秒后：开始显示画中画
   - 结束前5秒：回到纯口播

2. **循环播放**
   - 多个展示视频可以循环播放
   - 自动循环直到口播结束前5秒

3. **画中画位置**
   - 可调整位置（左上、右上、左下、右下、居中）
   - 可调整大小（占比）

4. **视频叠加**
   - 使用 MoviePy 的 CompositeVideoClip
   - 保持口播视频的音频

| 位置 | 说明 | X坐标 | Y坐标 |
|------|------|-------|-------|
| `top-left` | 左上角 | `10` | `10` |
| `top-right` | 右上角 | `w-pip_w-10` | `10` |

| `bottom-right` | 右下角 | `w-pip_w-10` | `h-pip_h-10` |
| `center` | 居中 | `(w-pip_w)/2` | `(h-pip_h)/2` |

## 🔧 技术实现

### 使用 MoviePy CompositeVideoClip

```python
from moviepy.editor import VideoFileClip, CompositeVideoClip

# 加载主视频（口播）
host_clip = VideoFileClip("口播视频.mp4")

# 加载展示视频
showcase_clip = VideoFileClip("店铺环境.mp4")

# 调整展示视频大小和位置
showcase_clip = showcase_clip.resize(width=w*0.3).set_position(('right', 'top'))

# 创建画中画效果
final_clip = CompositeVideoClip([host_clip, showcase_clip])
```

## 📝 参数配置

### 函数参数

```python
def add_picture_in_picture(
    host_video: str,                    # 主视频（口播视频）路径
    showcase_videos: List[str],         # 展示视频列表（店铺环境、产品等）
    output_path: Optional[str] = None, # 输出路径
    start_time: float = 3.0,            # 画中画开始时间（秒）
    end_before: float = 5.0,            # 结束前多少秒停止画中画
    position: str = 'bottom-right',      # 画中画位置
    size_ratio: float = 0.3,            # 画中画大小占比（0.1-0.5）
    loop: bool = True                   # 是否循环播放展示视频
) -> Optional[Path]:
```

## 🎬 使用示例

### 示例1: 基础画中画（右下角，30%大小）

```python
from ai_pipeline.video_editor import add_picture_in_picture

result = add_picture_in_picture(
    host_video="口播视频.mp4",
    showcase_videos=["店铺环境.mp4", "产品展示.mp4"],
    start_time=3.0,        # 3秒后开始
    end_before=5.0,        # 结束前5秒停止
    position='bottom-right',  # 右下角
    size_ratio=0.3        # 30%大小
)
```

### 示例2: 多个展示视频循环（左上角，20%大小）

```python
result = add_picture_in_picture(
    host_video="口播视频.mp4",
    showcase_videos=[
        "店铺环境.mp4",
        "工作流程.mp4",
        "产品展示1.mp4",
        "产品展示2.mp4"
    ],
    start_time=3.0,
    end_before=5.0,
    position='top-left',
    size_ratio=0.2,
    loop=True  # 循环播放所有展示视频
)
```

### 示例3: 居中大画中画（40%大小）

```python
result = add_picture_in_picture(
    host_video="口播视频.mp4",
    showcase_videos=["产品展示.mp4"],
    start_time=3.0,
    end_before=5.0,
    position='center',
    size_ratio=0.4
)
```
