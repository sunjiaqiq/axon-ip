# 自然语言元素定位实现说明

## 概述

已按照 IFLOW 的方式实现了自然语言元素定位功能，使抖音发布流程更加健壮和灵活。

## 实现的功能

### 1. 自然语言元素定位工具

#### `browser_click(element: str, ref: Optional[str] = None)`
- **功能**：点击页面元素（使用自然语言描述）
- **示例**：`browser_click("选择封面按钮")`、`browser_click("标题")`、`browser_click("完成按钮")`
- **定位策略**：
  1. 精确文本匹配
  2. 包含文本匹配
  3. 按钮角色匹配
  4. aria-label 属性匹配
  5. title 属性匹配
  6. placeholder 属性匹配
  7. div/span 文本匹配

#### `browser_fill(element: str, text: str, ref: Optional[str] = None)`
- **功能**：填写输入框（使用自然语言描述）
- **示例**：`browser_fill("标题输入框", "我的视频标题")`
- **定位策略**：与 `browser_click` 相同，优先查找输入框元素

#### `browser_file_upload(file_path: str, element: Optional[str] = None)`
- **功能**：上传文件（使用自然语言描述或自动查找）
- **示例**：`browser_file_upload("path/to/file.jpg", "上传封面")`
- **定位策略**：如果提供元素描述，使用自然语言定位；否则自动查找文件输入框

### 2. 发布流程改造

所有发布步骤都已改为使用自然语言定位，并保留备用方法：

1. **上传视频**：使用 `browser_file_upload`
2. **选择封面**：使用 `browser_click("选择封面按钮")`
3. **点击标题**：使用 `browser_click("标题")`
4. **点击 canvas**：保留原有逻辑（canvas 定位较特殊）
5. **上传封面文件**：使用 `browser_file_upload`
6. **点击确定**：使用 `browser_click("确定按钮")`
7. **点击完成**：使用 `browser_click("完成按钮")`
8. **填写标题**：使用 `browser_fill("标题输入框", title)`
9. **填写描述**：使用 `browser_fill("描述输入框", description)`
10. **点击发布**：使用 `browser_click("发布视频按钮")`

## 优势

1. **更健壮**：不依赖硬编码的 CSS 选择器，页面更新时仍能工作
2. **更灵活**：支持多种定位策略，提高成功率
3. **更易维护**：使用自然语言描述，代码更易理解
4. **向后兼容**：保留备用方法，确保在自然语言定位失败时仍能工作

## 使用方式

### 方式1：直接调用 MCP 工具（推荐）

在 GLM 5 或其他 MCP Client 中调用：

```python
# 点击元素
await browser_click("选择封面按钮")

# 填写输入框
await browser_fill("标题输入框", "我的视频标题")

# 上传文件
await browser_file_upload("path/to/file.jpg", "上传封面")
```

### 方式2：使用完整的发布函数

```python
await _publish_video_impl(
    video_path="path/to/video.mp4",
    title="我的视频标题",
    description="我的视频描述",
    cover_path="path/to/cover.jpg"  # 可选
)
```
