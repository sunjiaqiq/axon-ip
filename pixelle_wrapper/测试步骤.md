# Pixelle-Video Wrapper 测试步骤

## 📋 测试流程

### 第一步：单独测试 PixelleWrapper.exe

#### 1.1 启动 Wrapper 服务

**方式 A：使用 EXE（推荐）**
```bash
cd dist/Axon_Program/pixelle_wrapper
PixelleWrapper.exe
```

**方式 B：使用 Python 脚本（开发环境）**
```bash
cd pixelle_wrapper
python main.py
```

**预期输出：**
```
🚀 启动 Pixelle-Video Wrapper 服务...
INFO:     Started server process [xxxx]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:38887
```

#### 1.2 测试服务是否正常

**方式 A：使用测试脚本（推荐）**
```bash
cd pixelle_wrapper
python test_wrapper.py
```

**方式 B：手动测试（使用浏览器或 curl）**

1. **健康检查**
   ```bash
   curl http://127.0.0.1:38887/health
   ```
   预期响应：
   ```json
   {"status": "ok"}
   ```

2. **设置 API Key**
   ```bash
   curl -X POST http://127.0.0.1:38887/api/set_key \
     -H "Content-Type: application/json" \
     -d "{\"api_key\": \"你的API_KEY\"}"
   ```

3. **设置文案**
   ```bash
   curl -X POST http://127.0.0.1:38887/api/text \
     -H "Content-Type: application/json" \
     -d "{\"text\": \"测试文案\"}"
   ```

#### 1.3 验证服务状态

- ✅ 服务启动成功，无错误日志
- ✅ 健康检查返回 `{"status": "ok"}`
- ✅ API 接口可以正常调用

---

### 第二步：测试主 UI 集成

#### 2.1 确保 Wrapper 服务已启动

如果第一步测试通过，可以：
- **选项 A**：保持 Wrapper 服务运行（手动启动的）
- **选项 B**：关闭手动启动的服务，让主 UI 自动启动

#### 2.2 启动主程序

```bash
# 开发环境
python pyqt_main_axon.py

# 或打包后的程序
dist/Axon_Program/Axon.exe
```

#### 2.3 检查启动日志

主程序启动时应该看到：
```
[启动] 正在启动 Pixelle-Video Wrapper 服务...
[Wrapper] 服务未运行，正在启动...
[Wrapper] ✅ 服务启动成功
[启动] ✅ Wrapper 服务已就绪
```

#### 2.4 测试 UI 功能

1. 点击主界面右上角的 **"AI生成视频"** 按钮
2. 在对话框中：
   - 点击 **"配置 API Key"** 按钮，设置 API Key
   - 点击 **"上传人物形象"**，选择图片
   - 输入文案
   - 点击 **"生成视频"**

#### 2.5 验证完整流程

- ✅ 上传人物形象成功
- ✅ 文案设置成功
- ✅ 视频生成任务创建成功
- ✅ 进度条正常更新
- ✅ 视频生成完成后可以下载

## 🔍 故障排查

### 问题 1: 连接被拒绝 (Connection refused)

**症状：**
```
HTTPConnectionPool(host='127.0.0.1', port=38887): Max retries exceeded
```

**解决方案：**
1. 检查 Wrapper 服务是否正在运行
2. 检查端口 38887 是否被占用
3. 查看 Wrapper 启动日志，确认服务是否成功启动

### 问题 2: 服务启动失败

**症状：**
```
[Wrapper] ⚠️ 服务启动超时
```

**解决方案：**
1. 手动启动 `PixelleWrapper.exe`，查看详细错误信息
2. 检查 `pixelle_wrapper/main.py` 中的 Pixelle-Video 路径是否正确
3. 确认 Pixelle-Video 项目已正确安装

### 问题 3: 上传失败

**症状：**
```
上传失败: HTTPConnectionPool...
```

**解决方案：**
1. 确保 Wrapper 服务正在运行
2. 检查文件路径是否正确
3. 查看 Wrapper 服务日志
