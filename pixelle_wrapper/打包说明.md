# Pixelle-Video Wrapper EXE 打包说明

## 快速打包

### 方式1：使用打包脚本（推荐）
```bash
cd pixelle_wrapper
python build_exe.py
```

### 方式2：使用 PyInstaller 直接打包
```bash
cd pixelle_wrapper
pip install pyinstaller
pyinstaller --onefile --console --name=PixelleWrapper main.py
```

### 方式3：使用 spec 文件
```bash
cd pixelle_wrapper
pip install pyinstaller
pyinstaller build_exe.spec
```

## 打包前准备

### 1. 安装依赖
```bash
pip install -r requirements_build.txt
```

### 2. 检查主文件
确保 `main.py` 文件存在且可运行：
```bash
python main.py
```

## 打包后文件位置

打包完成后，EXE 文件在：
```
pixelle_wrapper/dist/PixelleWrapper.exe
```

## 运行 EXE

### 方式1：双击运行
直接双击 `PixelleWrapper.exe`

### 方式2：命令行运行
```bash
PixelleWrapper.exe
```

## 注意事项

1. **Pixelle-Video 路径**：EXE 运行时，需要确保 `Y:/Video-main` 路径存在
   - 如果路径不同，需要修改 `main.py` 中的 `PIXELLE_VIDEO_PATH`
   - 或者将路径作为环境变量传入

2. **依赖检查**：EXE 是独立的，不需要安装 Python 环境
   - 但需要确保 Pixelle-Video 项目在正确位置

3. **首次运行**：EXE 首次运行可能需要几秒钟解压

4. **控制台窗口**：EXE 会显示控制台窗口，可以看到日志输出

## 测试建议

1. **本地测试**：
   ```bash
   # 先测试 Python 版本
   python main.py
   
   # 确认正常后再打包
   python build_exe.py
   
   # 测试 EXE
   dist\PixelleWrapper.exe
   ```

2. **功能测试**：
   - 打开浏览器访问 `http://127.0.0.1:38887/docs`
   - 测试所有 API 接口
   - 使用 PyQt UI 测试完整流程

3. **错误排查**：
   - 查看控制台输出
   - 检查 Pixelle-Video 路径是否正确
   - 确认端口 38887 未被占用

## 常见问题

### Q: 打包失败
A: 检查是否安装了 PyInstaller：
```bash
pip install pyinstaller
```

### Q: EXE 运行失败
A: 检查：
1. Pixelle-Video 路径是否正确
2. 查看控制台错误信息
3. 确认所有依赖都已包含

### Q: EXE 文件太大
A: 这是正常的，因为包含了所有 Python 依赖和 FastAPI/uvicorn

### Q: 如何隐藏控制台窗口
A: 修改 `build_exe.spec` 或打包命令：
```python
console=False,  # 改为 False
```
