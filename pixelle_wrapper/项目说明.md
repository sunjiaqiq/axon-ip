# Pixelle-Video FastAPI Wrapper 项目说明

## 项目概述

这是一个**真正的 FastAPI Wrapper 服务**，为 PyQt UI 提供稳定的 REST API 接口。

## 架构说明

```
PyQt UI
   ↓ HTTP (REST API)
FastAPI Wrapper（本服务 - 新加的代码）
   ↓ Python 函数调用（直接 import）
Pixelle-Video 内部生成逻辑（原生代码，不修改）
```

## 代码分类

### ✅ Wrapper 代码（新加的）
- `pixelle_wrapper/main.py` - 所有 FastAPI 路由和状态管理
- `CURRENT_STATE` 字典 - 存储 avatar_path、text、api_key
- `TASKS` 字典 - 管理任务状态和进度
- 进度回调函数 - 将 Pixelle-Video 的进度事件转换为 Wrapper 的进度

### ✅ Pixelle-Video 原生逻辑（不修改）
- `PixelleVideoCore` 类 - 核心服务
- `generate_video()` 方法 - 真实的生成函数
- 所有 pipeline 和 service 代码

## 关键实现细节

### 1. 初始化 Pixelle-Video
```python
# 添加路径到 sys.path
PIXELLE_VIDEO_PATH = Path("Y:/Video-main")
sys.path.insert(0, str(PIXELLE_VIDEO_PATH))

# 导入原生代码
from pixelle_video.service import PixelleVideoCore

# 初始化
_pixelle_video = PixelleVideoCore()
await _pixelle_video.initialize()
```

### 2. 调用真实生成函数
```python
# 直接调用 Pixelle-Video 的生成函数
result = await _pixelle_video.generate_video(
    text=text,
    mode="fixed",
    frame_template="1080x1920/default.html",
    n_scenes=5,
    progress_callback=progress_callback
)
```

### 3. 进度跟踪
```python
def progress_callback(event):
    """将 Pixelle-Video 的进度事件转换为 Wrapper 的进度"""
    progress_percent = int(event.progress * 100)
    TASKS[task_id]["progress"] = progress_percent
```

## API 接口说明

### 1. GET /health
健康检查，返回 `{"status": "ok"}`

### 2. POST /api/set_key
设置 API Key，写入 `os.environ` 和 `CURRENT_STATE`

### 3. POST /api/avatar
上传数字人形象，保存到 `Y:/Video-main/data/avatars/`

### 4. POST /api/text
设置口播文案，存储到 `CURRENT_STATE["text"]`

### 5. POST /api/generate
生成视频，后台线程执行，返回 `task_id`

### 6. GET /api/task/{task_id}
查询任务状态，返回 `status`、`progress`、`output`

### 7. GET /api/download/{task_id}
下载生成视频，返回视频文件

## 与 PyQt UI 的集成

### UI 调用流程
1. `GET /health` - 检查服务
2. `POST /api/set_key` - 设置 API Key
3. `POST /api/avatar` - 上传人物照片
4. `POST /api/text` - 设置文案
5. `POST /api/generate` - 开始生成
6. `GET /api/task/{task_id}` - 轮询进度（每2秒）
7. `GET /api/download/{task_id}` - 下载视频

### UI 客户端代码
位置：`lib/adapter/pixelle_client.py`

已更新为调用 Wrapper API，不再直接调用不存在的 Pixelle-Video API。

## 注意事项

1. **不修改 Pixelle-Video 原生代码**：所有修改都在 Wrapper 中
2. **真实调用生成函数**：直接 import 并调用 `generate_video()`

4. **错误处理**：所有错误都记录到任务状态中

## 故障排除

### 问题：无法导入 Pixelle-Video
- **检查**：`Y:/Video-main` 路径是否正确
- **解决**：修改 `main.py` 中的 `PIXELLE_VIDEO_PATH`

### 问题：生成失败
- **检查**：API Key 是否已设置
- **检查**：文案是否已设置
- **检查**：查看控制台错误信息

### 问题：进度不更新
- **检查**：任务状态是否为 "running"
- **检查**：进度回调是否正常调用
- **解决**：查看控制台日志
