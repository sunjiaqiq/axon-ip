## 🎵 核心函数 `add_background_music` 内部逻辑

### 步骤1：文件验证

```python
# 1. 检查MoviePy是否安装
if VideoFileClip is None:
    return None  # 未安装，退出

# 2. 检查视频文件是否存在
if not video_path.exists():
    return None  # 不存在，退出

# 3. 检查音乐文件是否存在
if not music_path.exists():
    return None  # 不存在，退出
```

---

### 步骤2：加载视频和音频

```python
# 1. 加载视频文件
video_clip = VideoFileClip(str(video_path))
video_duration = video_clip.duration  # 获取视频时长（秒）

# 2. 加载背景音乐文件
background_music = AudioFileClip(str(music_path))
music_duration = background_music.duration  # 获取音乐时长（秒）
```

---

### 步骤3：处理音乐时长（关键逻辑）

```python
if loop and music_duration < video_duration:
    # 情况1：音乐比视频短，且需要循环播放
    # 循环播放音乐直到和视频一样长
    background_music = background_music.loop(duration=video_duration)
    
elif music_duration > video_duration:
    # 情况2：音乐比视频长
    # 裁剪音乐到视频长度
    background_music = background_music.subclip(0, video_duration)
    
else:
    # 情况3：音乐和视频长度一致
    # 不需要处理，直接使用
    pass
```

**逻辑说明**：
- ✅ **循环播放**：如果音乐短，自动循环到视频长度
- ✅ **自动裁剪**：如果音乐长，自动裁剪到视频长度
- ✅ **完美匹配**：确保音乐和视频长度一致

---

### 步骤4：调整音量

```python
# 1. 调整原视频音频音量
if video_clip.audio is not None:
    original_audio = video_clip.audio.volumex(original_volume)
    # volumex(1.0) = 100%音量
    # volumex(0.5) = 50%音量
else:
    original_audio = None  # 视频没有音频轨道

# 2. 调整背景音乐音量
background_music = background_music.volumex(music_volume)
# volumex(0.08) = 8%音量
# volumex(0.15) = 15%音量
```

**音量计算**：
- `volumex(1.0)` = 100% 原始音量
- `volumex(0.5)` = 50% 原始音量
- `volumex(0.08)` = 8% 原始音量

---

### 步骤5：应用淡入淡出效果（可选）

```python
if fade_in > 0:
    # 淡入效果：音乐从0音量逐渐增加到设定音量
    background_music = background_music.fadein(fade_in)
    # 例如：fadein(2.0) = 前2秒淡入

if fade_out > 0:
    # 淡出效果：音乐从设定音量逐渐减少到0
    background_music = background_music.fadeout(fade_out)
    # 例如：fadeout(2.0) = 后2秒淡出
```

**当前脚本设置**：
- `fade_in=0.0` - 无淡入效果
- `fade_out=0.0` - 无淡出效果

---

### 步骤6：混合音频

```python
if original_audio is not None:
    # 情况1：视频有原音频
    # 将原音频和背景音乐混合
    composite_audio = CompositeAudioClip([original_audio, background_music])
    # 两个音频同时播放，音量叠加
else:
    # 情况2：视频没有原音频
    # 只使用背景音乐
    composite_audio = background_music
```

**音频混合原理**：
- 原音频（100%）+ 背景音乐（8%）= 混合音频
- 两个音频轨道同时播放
- 音量不会互相覆盖，而是叠加

---

### 步骤7：合成最终视频

```python
# 1. 将混合后的音频设置到视频上
final_video = video_clip.set_audio(composite_audio)

# 2. 输出视频文件
final_video.write_videofile(
    str(output_path),
    codec='libx264',      # 视频编码：H.264
    audio_codec='aac',    # 音频编码：AAC
    fps=30,               # 帧率：30帧/秒
    preset='medium',      # 编码预设：中等质量
    bitrate='8000k'       # 视频比特率：8000kbps
)
```

**编码参数说明**：
- `codec='libx264'` - H.264视频编码，兼容性好
- `audio_codec='aac'` - AAC音频编码，质量好
- `fps=30` - 30帧/秒，流畅播放
- `preset='medium'` - 编码速度和质量平衡
- `bitrate='8000k'` - 8Mbps，高质量视频

---

### 步骤8：清理资源

```python
# 关闭所有视频和音频对象，释放内存
final_video.close()
video_clip.close()
background_music.close()
if original_audio is not None:
    original_audio.close()
composite_audio.close()
```

**为什么需要清理**：
- MoviePy对象占用大量内存
- 不关闭会导致内存泄漏
- 确保资源正确释放
