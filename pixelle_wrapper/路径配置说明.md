# 路径自动配置说明

## 概述

`pixelle_wrapper` 现在支持**自动路径检测**，无需手动配置硬编码路径。所有路径都会根据运行环境自动匹配。

## 路径检测顺序

### 1. Pixelle-Video 项目路径检测

系统会按以下顺序自动检测 Pixelle-Video 项目路径：

1. **环境变量**：`PIXELLE_VIDEO_ROOT` 或 `PIXELLE_VIDEO_PATH`
2. **父目录**：检查 `pixelle_wrapper` 的父目录（开发环境）
3. **同级目录**：检查 `pixelle_wrapper` 的同级目录（打包环境）
   - 可能的目录名：`Video-main`, `Video`, `pixelle-video`, `Pixelle-Video`
4. **当前工作目录**：检查当前工作目录
5. **已安装模块**：如果 `pixelle_video` 已作为包安装，从模块路径推断

### 2. 数据目录

所有数据文件（头像、产品图片、音频）存储在：
```
pixelle_wrapper/data/
├── avatars/    # 数字人形象
├── products/   # 产品图片
└── audios/     # 音频文件
```

**优势**：
- 数据文件与 wrapper 在一起，便于打包
- 打包后可以独立运行，不依赖外部路径

### 3. 配置文件查找

`config.yaml` 查找顺序：
1. `PIXELLE_VIDEO_PATH/config.yaml`
2. `pixelle_wrapper/config.yaml`
3. `当前工作目录/config.yaml`

### 4. 输出目录查找

输出目录查找顺序：
1. `PIXELLE_VIDEO_PATH/output`
2. `PIXELLE_VIDEO_PATH/outputs`
3. `pixelle_wrapper/output`
4. `pixelle_wrapper/outputs`

如果都找不到，会在 `pixelle_wrapper/output` 自动创建。

## 环境变量配置（可选）

如果需要手动指定路径，可以设置环境变量：

### Windows
```cmd
set PIXELLE_VIDEO_ROOT=D:\Projects\Video-main
```

### Linux/Mac
```bash
export PIXELLE_VIDEO_ROOT=/path/to/Video-main
```

### Python 代码中设置
```python
import os
os.environ["PIXELLE_VIDEO_ROOT"] = "D:/Projects/Video-main"
```

## 打包后的路径结构

打包后的推荐目录结构：

```
安装目录/
├── pixelle_wrapper/
│   ├── PixelleWrapper.exe    # 或 main.py
│   ├── data/                  # 数据目录
│   │   ├── avatars/
│   │   ├── products/
│   │   └── audios/
│   ├── output/                # 输出目录
│   ├── config.yaml           # 配置文件（可选）
│   └── requirements.txt      # 依赖列表
└── Video-main/               # Pixelle-Video 项目（可选，如果使用环境变量则不需要）
    ├── pixelle_video/
    ├── workflows/
    └── config.yaml
```

## 常见问题

### Q: 如何确认路径检测是否成功？

A: 查看启动日志，会显示：
```
[Wrapper] 从环境变量检测到 Pixelle-Video 路径: D:\Projects\Video-main
[Wrapper] 已设置 PIXELLE_VIDEO_ROOT: D:\Projects\Video-main
[Wrapper] Wrapper 基础目录: D:\Projects\Axon_yuan\pixelle_wrapper
```

### Q: 如果检测失败怎么办？

A: 
1. 检查日志中的警告信息
2. 设置环境变量 `PIXELLE_VIDEO_ROOT`
3. 确保 `pixelle_video` 模块可以导入（已安装或路径正确）

### Q: 打包后路径检测会失败吗？

A: 不会。系统会：
1. 优先检查环境变量
2. 检查同级目录（打包后通常在同一安装目录下）
3. 如果 `pixelle_video` 已作为包安装，会自动检测

### Q: 数据文件存储在哪里？

A: 所有数据文件存储在 `pixelle_wrapper/data/` 目录下，与 wrapper 在一起，便于打包和独立运行。

## 注意事项

1. **不要硬编码路径**：所有路径都应该通过自动检测或环境变量配置
2. **数据目录**：数据文件存储在 wrapper 目录下，确保有写入权限
3. **配置文件**：如果使用自定义 `config.yaml`，可以放在 wrapper 目录下
4. **输出目录**：输出目录会自动创建，无需手动创建
